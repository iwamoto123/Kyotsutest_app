# 共通テスト攻略ノート

共通テストの問題冊子をめくる感覚で遊べる、スマートフォン向けの英語学習ゲームです。白い紙面、明朝体とセリフ体、解答番号、赤ペン採点を中心にしたデザインです。

## できること

- 本文・設問ページをタブ、ページの角、左右スワイプで行き来する
- 設問を本文の下へ挟み、見比べながら解く
- 問1〜問3を選び、本文の文をタップして解答根拠に青線を引く。採点後は正解の赤い二重線と比較する
- 選択肢を横へ払って消去する（再度払うと解除）
- 「対訳ヒント」を押しながら文をタップして、英文の直下に日本語を表示する。短いタップで切替、パソコンでは H キーも使用可能
- 単語を長押しして意味を確認し、端末の単語帳に保存する
- 3分・3問の演習を解き、赤ペンの採点と連続正解を楽しむ
- 解答後に根拠と解説を確認する
- 復習で本文・設問・選択肢の全訳を英文の直下に表示する（表示切替可能）
- 本文の英語音声を0.75 / 1 / 1.25倍速で聴き、再生中の文を追いかける
- 通し再生、1文リピート、1文聴いてから自分で発音する練習を選ぶ。文をタップするとそこから再生する

辞書・単語帳を開いている間はタイマーが止まります。保存単語はブラウザーの localStorage に残り、再読み込み後も使えます。端末間の同期はありません。保存を許可しないブラウザーでは画面を開いている間だけ保持します。

## 開発

Node.js 24 を推奨します（22.13以上が必要です）。

```sh
npm ci
npm run dev
```

開発サーバーが表示するローカルURLを開いてください。

```sh
npm test
npm run typecheck
npm run lint
npm run build
```

React / TypeScript / Vinext / Tailwind CSS / Shadcn UI を使用しています。Sites向けの設定は `.openai/hosting.json` にあり、認証情報やAPIキーは含みません。

`lint` はアプリと直接利用しているUIを対象にしています。未使用のShadcn標準コンポーネントは、今後の拡張用に初期状態のまま保持しています。採点・タイマー・根拠の表示・辞書の収録範囲・音声キューの動作は自動テストで検証しています。

依存関係はSites標準構成を基準にしています。React関連はセキュリティ修正版の19.2.8へ更新済みですが、初期構成に由来する他の `npm audit` の指摘は残っています。一般公開や外部入力を扱う機能の追加時には、依存関係を再評価してください。

## 復習と音声

3問の解答確定または時間切れの後、「全訳・音声で復習」へ進みます。自分の下線と正解の根拠を比較し、全訳・音声で読み直せます。復習の操作で演習時の得点・根拠・ヒント回数は変わりません。

音声は Web Speech API の端末内蔵の英語読み上げ機能を使います。音声の種類・発音品質・利用可否は端末とブラウザーに依存します。初回の再生はユーザーの操作から開始し、英語音声の取得失敗や再生不可時には再試行を表示します。マイク・録音・発音判定は使いません。一時停止からの再開や速度・モード変更は、現在の文の先頭からです。辞書、設問ページ、別アプリへの移動時は停止し、復帰しても自動再生しません。

自動テストでは音声エンジンを置き換え、停止後の遅延イベントや反復タイマーを検証しています。実機での発声と音質は端末で確認してください。

## 現在の範囲

英語リーディングのオリジナル演習1セット（3問）を収録した操作プロトタイプです。大学入試センターの公式サービスではなく、実際の過去問本文は転載していません。本試験の得点・偏差値の推定、全科目対応、過去問取り込み、AI問題生成、学習履歴のサーバー保存は未実装です。得点はこの演習内の6点満点で、ヒントは減点しません。

紙面構成は[大学入試センターの令和8年度本試験問題](https://www.dnc.ac.jp/kyotsu/kakomondai/r8/r8_honshiken_mondai.html)を参考にしています。

主な実装は `app/page.tsx`（画面・ジェスチャー）、`app/globals.css`（紙面デザイン）、`lib/exam-content.ts`（問題と対訳）、`lib/exam-engine.ts`（採点・タイマー）、`lib/vocabulary.json`（収録語彙）です。
