# 共通テスト攻略ノート

共通テストの問題冊子をめくる感覚で遊べる、スマートフォン向けの英語学習ゲームです。白い紙面、明朝体とセリフ体、解答番号、赤ペン採点を中心にしたデザインです。スクロールする紙面と、親指で使う下部のガイド・操作欄を分けています。

## できること

- 本文・問1・問2・問3の4ページを左右のスワイプでめくる。縦方向はスクロールし、各ページの読んでいた位置を保つ。下部の矢印と紙面の角からも移動できる
- 設問を本文の下へ挟み、見比べながら解く
- 選択肢の左の□をチェックして1つだけ選び、下部の「解答をチェック」で採点する。選択肢内の英単語のタップは辞書として使える
- 普段は読む・めくる・単語をタップする。「書き込む」から線を引く・文を保存・訳を見る操作を選び、1回使うと通常の読書操作へ戻る
- 「線を引く」で英文を指でなぞり、単語単位の青線を引く。逆向き・複数行のなぞりと、未採点の線の取り消しに対応する
- 「文を保存」で訳せなかった部分をなぞると、該当する文全体・日本語訳・なぞった箇所を保存する
- 英単語をそのままタップし、意味と使用文を確認して保存する。長押しや辞書モードへの切り替えは不要
- 「この文の訳を見る」で文をタップし、英文を残したまま直下に日本語を表示する
- ガイドありで「場面を確認 → 設問を整理 → 根拠をなぞる → 選択肢を選ぶ」を練習する。場面・探すこと・根拠が日本語の整理メモに残る
- 紙面とガイドに同じ番号の目印を表示し、導入文・設問文・本文・選択肢のどこを見るかを示す。対象が画面外なら上下の方向や移動先ページを表示し、タップで戻れる
- 日本語の整理と判定は、対象の英文のすぐ下に表示する。解答時は根拠の原文を選択肢の前に置き、照合できる
- なぞった箇所や誤答に応じて具体的な確認ポイントを表示し、「次に確認」へ保存する。説明を読んで選び直せる
- ガイドなしで3分・3問の演習を解く。選択肢の消去ボタン、赤ペン採点、連続正解を使える
- 採点後は「次の問へ」、全問終了後は「結果・復習へ進む」を表示する。誤答の選び直しと次の問へ進む操作を分けている
- 「わからない・中断」から、今の問の復習または途中の結果へ進める。結果画面には解説・全訳・音声・ノートの入口があり、復習中も4種類を直接切り替えられる
- 復習で本文・設問・選択肢の全訳を英文の直下に表示する（表示切替可能）
- 自分の下線と正解の赤い二重線を比較する
- 本文の英語音声を0.75 / 1 / 1.25倍速で聴き、再生中の文を追いかける
- 通し再生、1文リピート、シャドーイングを選ぶ。「この文を聴く」で任意の文から再生する。復習の種類を往復しても文の位置・速度・練習方法を引き継ぐ

ガイドあり・各パネル・結果・復習を開いている間はタイマーが止まります。途中の結果や復習から「解答を再開」すると、元のページ・スクロール位置・挟んだ設問・個別の訳表示を復元します。ガイドのオン・オフで下線や学習メモは消えません。選び直しても最初の採点結果を残します。

ガイドの段階が変わると見る場所まで移動します。自分でスクロールしたりページをめくったりしている間は引き戻しません。根拠を探す段階では本文全体に目印を付け、正解文の場所は判定後に示します。

「整理 / 単語 / 文 / 次に確認」のノートはブラウザーの localStorage に残り、再読み込み後も使えます。以前の単語帳も引き継ぎます。端末間の同期はありません。保存を許可しないブラウザーでは画面を開いている間だけ保持します。演習の途中再開と音声位置の保持はアプリを開いている間のみです。線を引く・文の保存中は英文をなぞり、紙面の余白からスクロールします。キャンセルすると通常の読書操作へ戻ります。

## 開発

Node.js 24 を推奨します（22.13以上が必要です）。

```sh
npm ci
npm run dev
```

開発サーバーが表示するローカルURLを開いてください。

```sh
npm test
npm run typecheck
npm run lint
npm run build
```

React / TypeScript / Vinext / Tailwind CSS / Shadcn UI を使用しています。Sites向けの設定は `.openai/hosting.json` にあり、認証情報やAPIキーは含みません。

`lint` はアプリと直接利用しているUIを対象にしています。未使用のShadcn標準コンポーネントは、今後の拡張用に初期状態のまま保持しています。採点・タイマー・なぞり範囲・ガイドの遷移・根拠判定・スワイプ方向・次の未回答への移動・ノートの復元・辞書の収録範囲・音声キューと設定復元は自動テストで検証しています。タッチ実機での指の追従や読み上げ品質は、自動テストの対象外です。

依存関係はSites標準構成を基準にしています。React関連はセキュリティ修正版の19.2.8へ更新済みですが、初期構成に由来する他の `npm audit` の指摘は残っています。一般公開や外部入力を扱う機能の追加時には、依存関係を再評価してください。

## 復習と音声

各問の採点後と、演習途中の「わからない・中断」から復習へ進めます。結果画面からも解説・全訳・音声・ノートを選べます。自分の下線と正解の根拠を比較し、全訳・音声で読み直せます。復習の操作で演習時の得点・根拠・ヒント回数は変わりません。未回答の解説も確認できますが、それだけで回答済みにはなりません。

音声は Web Speech API の端末内蔵の英語読み上げ機能を使います。音声の種類・発音品質・利用可否は端末とブラウザーに依存します。初回の再生はユーザーの操作から開始し、英語音声の取得失敗や再生不可時には再試行を表示します。マイク・録音・発音判定は使いません。一時停止からの再開や速度・練習方法の変更は、現在の文の先頭からです。辞書、設問ページ、別の復習、結果、別アプリへの移動時は停止し、復帰しても自動再生しません。

自動テストでは音声エンジンを置き換え、停止後の遅延イベントや反復タイマーを検証しています。実機での発声と音質は端末で確認してください。

## 現在の範囲

英語リーディングのオリジナル演習1セット（3問）を収録した操作プロトタイプです。ガイド・日本語整理・選択肢ごとの確認ポイントはこの3問用に作成し、根拠の照合は文とキーワードで判定します。AIによる自由文の理解判定や弱点診断ではありません。大学入試センターの公式サービスではなく、実際の過去問本文は転載していません。本試験の得点・偏差値の推定、全科目対応、過去問取り込み、AI問題生成、学習履歴のサーバー保存は未実装です。得点はこの演習内の6点満点で、ヒントは減点しません。

紙面構成は[大学入試センターの令和8年度本試験問題](https://www.dnc.ac.jp/kyotsu/kakomondai/r8/r8_honshiken_mondai.html)を参考にしています。

主な実装は `app/page.tsx`（画面と学習フロー）、`app/touch-text.tsx`（指の操作）、`app/study-guide.tsx`（ガイド）、`app/globals.css`（紙面デザイン）、`lib/study-interactions.ts`（なぞり範囲・ガイド・ノート）、`lib/exam-content.ts`（問題と対訳）、`lib/exam-engine.ts`（採点・タイマー）、`lib/vocabulary.json`（収録語彙）です。
